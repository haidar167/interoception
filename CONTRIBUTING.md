# Contributing to Interoception

Thank you for your interest in contributing to Interoception!

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/haidar167/interoception.git
   cd interoception
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   # On Windows: venv\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -e .
   ```

## Running Tests

Run tests using pytest:
```bash
python -m pytest
```

## Code Guidelines

- Follow PEP 8 style rules.
- Ensure all pytest tests pass cleanly before submitting a PR.
